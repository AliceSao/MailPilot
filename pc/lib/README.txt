# MailPilot PC - 依赖库目录
# 将以下jar包放入此目录：
# - okhttp-4.12.0.jar  (HTTP客户端)
# - okio-3.9.0.jar      (OkHttp依赖)
# - gson-2.10.1.jar     (JSON处理)
# - mailapi-1.6.7.jar   (JavaMail API核心)
# - imap-1.6.7.jar      (JavaMail IMAP提供者)
# - jskata-1.0.0.jar    (可选，WebSocket支持)
#
# 下载地址：
# OkHttp: https://mvnrepository.com/artifact/com.squareup.okhttp3/okhttp
# Okio: https://mvnrepository.com/artifact/com.squareup.okio/okio
# Gson: https://mvnrepository.com/artifact/com.google.code.gson/gson
# JavaMail API: https://mvnrepository.com/artifact/com.sun.mail/mailapi
# JavaMail IMAP: https://mvnrepository.com/artifact/com.sun.mail/imap
